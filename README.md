# Shambetov Koleno Experience

Landing page for traumatologist-orthopedist Zhantai Shambetov, built with Next.js.

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

The page auto-updates while editing files in `src`.

## Treatment information

The treatment section uses accessible cards and a focused information sheet. Each topic contains a short explanation, common symptoms, the usual diagnostic approach, and a consultation call to action. Medical copy is educational and must not be presented as an individual diagnosis.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.

## Verification

```bash
npx tsc --noEmit
npm run lint
npm run build
```
